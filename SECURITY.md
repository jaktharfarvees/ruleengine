# Security Policy

## Supported versions

No production version has been released. After `v1.0.0`, the current and
previous minor release lines will receive security fixes.

## Reporting a vulnerability

Report vulnerabilities privately to `security@arrowhr.com`. Include affected
versions, reproduction steps, impact, and any suggested mitigation. Do not open
a public issue and do not include real employee, tenant, payroll, or leave data.

The maintainers will acknowledge a report within two business days, provide a
tracking reference, and coordinate disclosure after a fix is available.
